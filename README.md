## 試行錯誤を通じたモデル改善

本コンペでは、人物が扇子を持っているかを判定する画像分類に取り組みました。背景に扇子が写っている場合や、持っている扇子が見切れている場合もあり、扇子の有無だけでは判断できない課題でした。

初めての画像分類コンペだったため、過去の上位解法から手法を学び、画像の特徴・誤分類・学習曲線を継続的に確認しながら、検証方法や学習条件を改善しました。

### データの偏りを踏まえた検証と学習条件の調整

画像を確認すると、撮影環境や明るさの分布に偏りがありました。そこで、正解ラベル・画像特徴によるクラスタ・明るさを組み合わせた層化分割を採用し、各foldの構成をそろえました。

また、大規模モデルは学習に時間がかかるため、まず小さいモデルで交差検証のスコアや学習曲線を確認しながら調整しました。その結果を踏まえ、大きいモデルでも学習率やデータ拡張の強さを調整しました。

| 改善段階 | 取り組み | 当時の記録におけるスコアの変化 |
| --- | --- | --- |
| 検証分割の見直し | ラベル・画像クラスタ・明るさを考慮したTriple Stratified K-foldを採用 | 約0.994 → 約0.998 |
| 学習条件の調整 | 学習曲線や検証結果を確認し、学習率・データ拡張などを調整 | 約0.998 → 0.999程度 |

### 実験結果に基づく手法の取捨選択

データの特徴から有効と考えた手法でも、実際にスコアが改善するとは限りませんでした。試行後は画像の変化や評価結果を確認し、採用・不採用を判断しました。

| 着目した課題 | 試したこと | 結果・判断 |
| --- | --- | --- |
| 明るさのばらつき | ガンマ補正と、明るさ・コントラストを変える補正を比較 | 当時の比較でスコアが高かったガンマ補正を採用 |
| 人物の動きによるブレ | モーションブラーを追加 | 背景にもブレが加わり、スコアも低下したため不採用 |
| 背景の扇子を「保持」と誤認する | 背景の扇子を削除 | 手に持つ扇子まで消してしまうケースがあり、スコアが低下したため不採用 |
| 背景の扇子への依存を減らす | パディング部分に扇子を追加 | スコアの改善が見られず不採用 |

特に背景への加工では、画像を変えることで、分類に必要な情報まで失う場合がありました。この経験から、加工後も画像と正解ラベルの対応が保たれているかを確認することを重視しました。

### 結果と振り返り

最終提出には、暫定評価で最も高いスコアを得たEVA/EVA02系6モデルの予測確率の単純平均を採用し、**最終提出F1は0.9991633**となりました。また、審査発表会を経て、**学生部門3位に入賞**しました。

一方、最終評価では単体モデルがアンサンブルを上回りました。追加モデルの価値は、スコアだけでなく、誤分類の傾向や学習・推論コストも含めて検証する必要があると考えています。

単体モデルとアンサンブルの提出結果、採用・不採用の判断、学習設定は、[実験と学習設定](docs/experiments.md)にまとめています。

## 実装でできること

モデル名による生成、共通の学習・推論、画像IDを照合する確率平均を実行できます。Triple Stratifiedの明るさ境界は、**学習画像の画像数がほぼ均等になる分位点**から求めます。提出用テスト画像は推論にだけ使います。

- モデルごとの正規化を設定・checkpointへ保存し、推論にも同じ値を使用します。
- 各画像を学習に使っていないfoldの最良checkpointからOOF予測を保存し、単体・平均のF1と誤分類を比較します。
- CSV、fold、モデル設定、checkpoint、予測の画像IDを照合し、取り違えを防ぎます。

各処理の責務と使用ライブラリは[実装範囲](docs/provenance.md)にまとめています。

## モデル名だけで作成

```python
from fan_classifier import build_model

model = build_model("eva_large_336")
```

分類ヘッドは2出力です。初回はtimmが提供する事前学習重みを取得します。構造だけを作る場合は `pretrained=False` を指定します。

| 選択名 | モデル | 入力サイズ | 既定fold数 |
| --- | --- | ---: | ---: |
| `eva02_large_448` | EVA02 Large | 448 | 3 |
| `eva_giant_560` | EVA Giant | 560 | 3 |
| `eva_giant_336` | EVA Giant | 336 | 5 |
| `eva_large_336` | EVA Large | 336 | 5 |
| `eva_giant_clip_224` | EVA Giant CLIP | 224 | 5 |
| `eva_large_196` | EVA Large | 196 | 5 |

完全なtimm識別子でも選択できます。モデルごとの入力サイズ・学習率・augmentationなどは [registry.py](src/fan_classifier/registry.py) に登録し、同じモデルの全foldに共通設定を適用します。foldとは、学習画像を複数の組に分け、検証用の組を順番に切り替える交差検証の単位です。

## 実行と評価

```bash
git clone https://github.com/yadorann24/signate-technopro-fan-classifier.git
cd signate-technopro-fan-classifier
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
fan-classifier list-models
fan-classifier describe-model --model eva_large_336
```

[再現手順](docs/reproduction.md)では、依存関係の固定、データ形式、Triple Stratified、学習、提出用推論を順番に説明しています。[OOF評価と比較実験](docs/evaluation.md)では、正規化の切り替えと、同じ画像IDで単体・アンサンブルを評価する方法を説明しています。

6構成を既定fold数で全て学習すると、合計26回のfold学習になります。まず1モデルのOOFを確認し、追加モデルによるF1の変化と推論コストを比較します。

SIGNATEの配布画像・ラベル、学習済み重み、特徴量、予測結果は同梱していません。実行には利用権限のあるデータを用意し、画像やデータから生成する成果物は非公開で管理してください。データの配置と入力形式は[再現手順](docs/reproduction.md#データの用意)に記載しています。
